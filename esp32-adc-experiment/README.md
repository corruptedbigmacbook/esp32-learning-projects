# ESP32 ADC DRIVER EXPERIMENT

This is a project demonstrating  ADC configuration  and calibartion using ESP-IDF



## Features
 - ADC1 CONFIGURATION
 - ADC channel setup
 - ADC attenuation configuration
 - ADC calibration
 - Raw ADC reading
 - Voltage configuration



##  Hardware 
 - ESP32 devkit
 - Capacitive Soil Moisture Sensor V2


## Concepts learned

 -ADC Units 
 -ADC Channels
 -Attenuation
 -Bit width 
 -Calibration 
 -Raw vs Calibrated Voltage
